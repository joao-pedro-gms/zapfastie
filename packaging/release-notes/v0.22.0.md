ZapFastie 0.22.0 turns Notes into a place to write. A note is now a page as wide as reading allows, centred in its pane, with markdown that takes shape as you type: headings, bold and italic, struck-through words, code, quotes, bullets, numbers and checkboxes. A row of buttons and the keyboard apply the same marks, Control+E (Command+E on a Mac) reads the note back with lists, quotes, code and links drawn, and a box in the reading view can be ticked with a click. The list groups notes under Pinned, Today, Yesterday, This week and Earlier, a search filters it without closing the note you are writing, and a note can be renamed by hand, duplicated, exported as a markdown file, or deleted after a confirmation.

## New

- **Notes is a page you write on.** The note keeps to a comfortable reading width, centred in its pane and filling it down to a line that counts the words and says when it was last written. Below 780 points of window the list steps aside and the header carries the way back. By @crmne.
- **Markdown takes shape while you type,** and what is stored is exactly what you typed: headings, bold, italic, struck-through words, inline code, quotes, bullets, numbers and checkboxes are drawn in place, under a caret that does not move. By @crmne.
- **A formatting row and its keys.** Nine buttons above the writing and Control+B, Control+I, Control+Shift+X and Control+K apply the mark over a selection and take it off again, and Enter carries a list on or starts a new box. While the Notes tab is open those keys belong to the note. By @crmne.
- **Control+E reads the note back,** with headings at their sizes, lists indented, quotes to the side, code in its own block with a button to copy it, links that open in your browser, and checkboxes you can tick with a click, which writes the tick into the note. By @crmne.
- **The list is grouped and searchable:** Pinned, Today, Yesterday, This week and Earlier, each row with the time it was last written and the words under its name, a bubble beside the time for a note that cites something, and a pin that shows on hover. A search filters the list and leaves the note you are writing open. By @crmne.
- **A note can be named by hand,** and the name stays as its first line changes. The header's menu duplicates a note with its pin and its citations, and exports it as a `.md` file into your downloads folder, taking a new number rather than writing over a file already there. By @crmne.
- **Deleting a note asks first,** naming the note it would delete, and a citation can be taken off with a right-click while the others stay. By @crmne.
- **An empty Notes tab offers to start a note,** in the list and in the pane beside it. By @crmne.

## Fixed

- **A checklist that follows plain bullets keeps its boxes.** In the reading view those lines came out as ordinary bullets, so no box was drawn and clicking one did not tick it. By @crmne.
- **An empty checkbox is visible** instead of being ruled in a colour one shade off the page. By @crmne.
- **Exporting a note with a long accented title** wrote a file with a broken name, and on some titles stopped the export; the name is now cut by characters and made safe for the file system. By @crmne.

## Known limitations

- The new words of the notes screen are translated as they arrive, but a few labels still show in English in other languages until translators pick them up. [Translations are welcome](https://github.com/joao-pedro-gms/zapfastie/issues/new?template=translation.yml).
- Notes are still local only: a note cannot yet be searched from the chat list, and mail is not built, so a note cites messages and not mail.
- Calls are still a work in progress, as described in [0.20.0](https://github.com/joao-pedro-gms/zapfastie/releases/tag/v0.20.0): video calls are in alpha, and in group calls your video stops for a moment every few seconds (#592).
